# FlowKeys Agent Handover Pack

This folder is the canonical handover bundle for agentic coding tools (Claude Code, Codex, Antigravity, etc.).

## Files in this folder
- `HANDOVER.md`: Operational handoff details, risks, and next steps.
- `ARCHITECTURE.md`: System architecture and component boundaries.
- `HOW_APP_WORKS.md`: End-to-end runtime behavior and user flows.
- `WHAT_IS_DONE.md`: Exact progress snapshot (completed vs pending).
- `NEXT_AGENT_PROMPT.md`: Ready-to-use continuation prompt for the next agent.

## Project intent
FlowKeys is a macOS menubar dictation app (SwiftUI + AppKit) based on Alt-Whisperflow, now being refactored to support multiple AI providers for:
- Speech-to-text transcription
- Post-processing / cleanup LLM

## Current reality
Implementation is partially complete and in-progress. Read `WHAT_IS_DONE.md` first before making additional edits.
